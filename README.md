# Neurones en PLS — pages légales

Ce dossier contient deux pages HTML statiques destinées à être publiées avec GitHub Pages :

- `terms.html` : conditions d’utilisation
- `privacy.html` : politique de confidentialité

## Avant publication

1. Remplacer `[AJOUTER UNE ADRESSE E-MAIL DE CONTACT]` dans les deux fichiers par une adresse de contact réellement consultée.
2. Vérifier que les descriptions de stockage et de traitement correspondent exactement au fonctionnement réel de votre script.
3. Ne jamais ajouter de jeton TikTok/Meta, clé API, mot de passe ou autre secret dans ce dépôt.

## Publication avec GitHub Pages

1. Créer un dépôt GitHub public, par exemple `neurones-en-pls-legal`.
2. Ajouter `terms.html`, `privacy.html` et éventuellement ce `README.md` à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Sous **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. Attendre que GitHub Pages publie le site.

Les URLs auront normalement cette forme :

- `https://VOTRE-PSEUDO.github.io/neurones-en-pls-legal/terms.html`
- `https://VOTRE-PSEUDO.github.io/neurones-en-pls-legal/privacy.html`

Remplacer `VOTRE-PSEUDO` par votre identifiant GitHub et vérifier que les deux pages s'ouvrent dans une fenêtre privée avant de les renseigner dans le portail développeur.

## Important

Ces modèles sont génériques. Ils ne constituent pas un avis juridique et ne garantissent pas l’acceptation par TikTok ou Meta. La politique doit décrire fidèlement les données réellement traitées par votre application. Si le script ne stocke pas les jetons localement, ou s’il utilise un autre stockage, adaptez la section correspondante.
